# School Fees

Monorepo npm avec React + Vite + TypeScript, Express + TypeScript, Prisma et PostgreSQL.

## Pré-requis

- Node.js 20+
- npm
- Docker + Docker Compose

## Installation

```bash
npm install
```

## Démarrage de l'environnement

```bash
docker compose up
```

## Vérification

- PostgreSQL: localhost:5432
- API: http://localhost:4000/health
- Frontend: http://localhost:5173

## Scripts utiles

```bash
npm run dev:api
npm run dev:web
```
